# isimbulamadimscript (IBS) v2.0 ☕
> Hata toleranslı, sıfır bağımlılıklı, oyunlar ve tarayıcı projeleri için gömülebilir (embeddable) hafif betik dili.

`isimbulamadimscript`, HTML5 oyunları ve web uygulamalarında mantık çalıştırmak için geliştirilmiş bağımsız bir mini betik dilidir.

---
